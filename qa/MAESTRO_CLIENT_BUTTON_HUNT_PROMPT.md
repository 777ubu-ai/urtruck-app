## 3. КАРТА ЭКРАНОВ И КНОПОК — ПРОЖАТЬ ВСЁ

Ниже — каждый клиентский экран и каждый интерактив. Создай по флоу на группу,
прогони, скриншоть. Кнопки без testID жми по **тексту** (RU указан).

### 3.1 Tab-bar (флоу `client-tabhunt.yaml`)
- Тапни по очереди: `bottom-nav-feed`, `bottom-nav-mywork`, `bottom-nav-publish`,
  `bottom-nav-profile`. После каждого — `waitForAnimationToEnd` + скриншот.
- `assertNotVisible: id: bottom-nav-queue`.
- Двойной быстрый тап по `bottom-nav-publish` (открой-закрой) — не должно
  дублировать экран/крашить.

### 3.2 Feed / лента (флоу `client-feedhunt.yaml`)
- Скролл ленты до конца (`scrollUntilVisible` или несколько `scroll`).
  Проверь: нет дубль-варнингов ключей (F11-смежное), карточки рендерятся,
  цена видна.
- `feed-lang-switch` — переключи язык, проверь что лента не сломалась, тексты
  перевелись. Верни RU.
- Фильтры: открой фильтр-лист, выбери тип кузова (пилюли), примен
  `filter-date-apply`, сбрось `filter-date-reset`. Скриншоты до/после.
- Сортировка по цене → проверь activeChip (F11) → закрой чип (✕).
- Тапни `trip-card` (рейс водителя) → откроется TripDetail.
- Тапни `cargo-card` → откроется CargoDetail.
- Тапни `driver-card` (если есть) → DriverDetail. Проверь акцент (F5) +
  отсутствие фейковых отзывов (F1-смежное).

### 3.3 CargoDetail — карточка груза (флоу `client-cargodetail.yaml`)
**Свой груз (есть ставки):**
- Открой свой груз с входящими ставками (MyWork → «Мои грузы» → tap карточки).
- На каждой ставке прожми: «Принять» (`Принять`), «Отклонить» (`Отклонить`),
  «Предложить свою цену» (`Предложить свою цену`).
- При «Предложить свою цену» открывается BidModal в counter-режиме:
  - проверь акцент оранжевый (F6-смежное),
  - быстрые чипы (+/-), ввод в `Своя цена`/`ownPrice`,
  - комментарий, «Отправить» (`sendBid`/`Отправить ставку`),
  - закрой модалку тапом по фону — не должна зависнуть.
- «Принять» ставку → должна создаться сделка, груз уходит в «Везут»,
  и НЕ остаётся в «Мои грузы» (проверь обе вкладки — это F8-связка,
  анти-дубль). Скриншоты.
**Свой груз (без ставок):** проверь F12.
**Удаление:** `my-cargo-delete-btn` (или из CargoDetail) → подтверждение →
тост «🗑 Груз удалён» → возврат. Груз исчез из списка.

### 3.4 TripDetail — рейс водителя глазами клиента (флоу `client-tripdetail.yaml`)
- Открой `trip-card`. Проверь акцент оранжевый (бордер цены, бар).
- `trip-detail-departure`, `trip-detail-arrival`, `trip-detail-truck` — видны.
- «Предложить цену» (`Предложить цену`) → BidModal create-режим → акцент
  оранжевый (F6) → отправь ставку → тост «Ставка отправлена!».
- Если есть блок сделки: «Подтвердить доставку», «Чат по заказу»,
  «Отменить сделку» — проверь цвета (F7) и что тап «Чат по заказу» открывает
  чат, а не крашит.

### 3.5 MyWork (флоу `client-myworkhunt.yaml`)
- 3 вкладки: `my-work-tab-searching` (Мои грузы), `my-work-tab-enroute` (Везут),
  `my-work-tab-delivered` (Доставлено). Тапни каждую + скриншот.
- Тогл архива `my-work-archive-toggle` → «Архив (N)» ↔ «К активным».
- В «Мои грузы»: `my-cargo-edit-btn` (F10), `my-cargo-delete-btn`.
- В «Везут»: `my-order-card` (F8), `deal-track-truck` (F9), «Подтвердить
  доставку», «Чат по заказу» (F7), «Отменить сделку» — только до выезда.
- Кнопка публикации `mytrips-publish-route`/`place_cargo` (Разместить груз) →
  открывает CreateCargo.
- Пустые состояния: если вкладка пуста — должен быть нормальный EmptyState с
  CTA, НЕ белый экран, НЕ demo-данные.

### 3.6 Publish / CreateCargo (флоу `client-createcargo.yaml`)
- `bottom-nav-publish` → `cargo-desc-input` виден.
- Заполни: описание (`cargo-desc-input`), маршрут (`cargo-from-input`,
  `cargo-to-input` — появляются после раскрытия пикера точки),
  вес (`cargo-weight-field`), объём (`cargo-volume-field`).
- Submit `cargo-submit-button` (Опубликовать груз).
- **F4:** скролл вниз — НЕТ кнопки «Сохранить черновик».
- Негатив: попробуй submit с пустым описанием — должна быть валидация/тост,
  НЕ молчаливый краш.
- После публикации груз появляется в MyWork → «Мои грузы».

### 3.7 Profile + EditProfile (флоу `client-profilehunt.yaml`)
- `bottom-nav-profile` → скриншот.
- **F2:** нет «Прямой импортёр» под именем.
- **F3:** нет кнопки «Стать водителем».
- `profile-my-reviews` → **F1** (нет фейковых отзывов).
- `profile-change-role` (Сменить роль) — тап, проверь что диалог осмысленный,
  отмени.
- `profile-push-filter`, `profile-pro-cta` — тапни, проверь что открывают
  экраны без краша.
- EditProfile: измени имя/город, `profile-save` — сохраняется, возврат.
- `profile-logout` — НЕ нажимай в середине прогона (разлогинит); проверь
  последним отдельным флоу.

## 4. СТРЕСС / НЕГАТИВ (флоу `client-stress.yaml`)
- Открой BidModal → введи `0` и отправь → должна быть ошибка «неверная сумма»,
  НЕ отправка нулевой ставки.
- Открой BidModal → введи текст/буквы → не должно крашить.
- Зайди в «Везут», открой трекинг, нажми назад на полпути загрузки карты — не
  должно крашить (web/iOS).
- Переключи язык на CN/EN в Feed, пройди в CargoDetail — все тексты переведены,
  нет голых ключей вида `cargo_deleted`.
- Быстрый двойной тап «Принять» на ставке → должна приняться ОДНА сделка
  (анти-дабл-accept), не две. Проверь «Везут».
