# P1-2 — Ручной тест-план: доставка push / APNS / lock-screen

**Статус: MANUAL — выполняется на реальном iPhone.** Автоматизировать нельзя:
APNS-доставка требует Apple Push сервиса + физического устройства; iOS-баннер/
lock-screen — системный UI вне иерархии приложения (Maestro его не видит).

## Предусловия

- [ ] Сборка из TestFlight **или** dev-client (`eas build -p ios --profile production|development`), bundle `com.urtruck.app`. Expo Go для remote-push на SDK 52 не годится.
- [ ] В EAS/Apple настроен **APNs Key** (Push Notifications capability). Без него токен есть, но доставки не будет.
- [ ] Реальный iPhone (push на симуляторе APNS не доставляется по-настоящему; `simctl push` — только локальная инъекция, см. `.maestro/10-foreground-push-suppress.yaml`).
- [ ] Два аккаунта/устройства: водитель и грузовладелец (для chat/bid push).
- [ ] В приложении выдано разрешение на уведомления (Settings → UrTruck → Notifications: Allow, Lock Screen + Banners + Sounds + Badges включены).

## Диагностика токена (dev-сборка)

- [ ] В Metro/Xcode-логах при логине видно `[push] projectId …`, `[push] expo token …`, `[push] register-native → 200` (логи добавлены в `src/utils/push.js`, P1-5).
- [ ] `GET /api/v1/system/info` на сервере → push-провайдеры в ожидаемом режиме.
- [ ] Self-test: `POST /api/v1/push/test` с Bearer токеном устройства → на телефон приходит «UrTruck / Тестовое уведомление».

## Критерий PASS

Все 15 пунктов отмечены. Особое внимание: **#2 (suppress) vs #1/#3 (show)** — это проверка P2-2; **#6/#9 (lock screen)** и **#5/#8 (killed)** — это собственно P1-2, не подтверждаемые без устройства.

## Если push НЕ доходит (типовые причины)

1. APNs Key не привязан в EAS credentials → токен есть, доставки нет.
2. `register-native` вернул не 2xx (см. dev-лог `[push]`) → токен не сохранён на сервере (проверка ответа добавлена в P1-5).
3. Сборка — Expo Go (`host.exp.Exponent`), а не standalone/dev-client с `com.urtruck.app`.
4. На сервере push_sender в mock/ошибка — проверить логи PM2 `urtruck-security-api` (фоновая отправка теперь в daemon-потоке, P1-аудит: ошибки печатаются `[push] background send failed …`).
5. У пользователя выключены уведомления в iOS Settings.
