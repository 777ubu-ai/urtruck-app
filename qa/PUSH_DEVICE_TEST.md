## Pre-flight
- 2 аккаунта: **A = грузоотправитель** (boris), **B = водитель** (test-driver/serik).
- Build установлен на iPhone (real device, НЕ симулятор — APNs в симуляторе нет).
- Backend `https://urtruck.kz` доступен (`curl .../api/v1/system/info` → 200).
- Wi-Fi/cellular включён.

## Базовые (из брифа)
1. **Permission popup** при первом запуске → «Allow». В логах backend:
   `register-native received token=ExponentPushToken[...]`; в БД
   `push_tokens_native` строка с `provider=expo, platform=ios` и **непустым user_id**.
   (⚠️ BUG-004: если `user_id` NULL — токен не привязался, пуши не дойдут.)
2. **APNs на lock screen**: A принимает ставку B → у B на локскрине пуш ≤5 сек.
3. **Badge на иконке**: после пуша красный кружок с числом на иконке приложения.
4. **Killed app → тап**: свайпнуть приложение, прислать пуш, тап → холодный старт
   СРАЗУ на нужный экран, без двойной анимации. (⚠️ BUG-006 — проверь, не
   дёргается ли навигация дважды.)
5. **Два устройства**: B прочитал чат на iPhone → badge на втором устройстве B
   обновился (если 2 девайса).
6. **Группировка iOS**: 4 сообщения → iOS summary → тап открывает нужный чат.
7. **Выключить уведомления в iOS Settings** → приложение не ломается, работает без пушей.

## Проверка найденных багов на устройстве
- **BUG-002 (P1, чинится в коде — перепроверь после фикса):** тап по пуш-баннеру
  «ставка принята / сделка / статус рейса» из **фона/убитого** приложения → должен
  открыться **Deal Room** (карточка сделки), а НЕ общий список чатов.
- **BUG-003 (P1, device-critical):** открой чат с непрочитанными, прочитай сообщения
  НЕ выходя на таб-бар → выйди → красный кружок на иконке приложения должен
  погаснуть (сейчас может зависнуть/быть завышен).
- **BUG-005 (P2):** тап по пушу «новая ставка» → CargoDetail/TripDetail открывается
  в правильном виде для роли (не дефолтный/чужой).
- **BUG-001 (P0, web/PWA):** после фикса — на PWA разреши пуши, проверь что в БД
  `push_subscriptions.user_id` НЕ NULL и web-push доходит адресно.
- **Suppress:** будучи ВНУТРИ чата комнаты X, получи сообщение в X → баннер НЕ
  показывается, сообщение появляется в ленте (foreground suppress).
- **Offline→online:** выключи сеть у B, A пишет сообщение, включи сеть → пуш
  доставляется (не теряется).
- **Self-push:** A ставит ставку на СВОЙ груз / пишет себе → пуш себе НЕ приходит.
- **Партнёр без имени:** собеседник без full_name → в тексте пуша phone-tail,
  не «Собеседник»/«None».
