## 1. ГЛАВНОЕ — ТОРГ В ЧАТЕ В ОБЕ СТОРОНЫ (критично, проверять первым)
Это то, из-за чего затевалось. Проверить, что у ОБЕИХ сторон в чате есть рабочие
кнопки-ответы (не «увидел цену и тупик»).

### 1A. Водитель предлагает → грузоотправитель отвечает
1. serik (driver) на чужом грузе жмёт «Предложить цену» → ставка $4 800.
2. boris (owner) получает пуш «💰 Ставка $4 800 · маршрут», тап по пушу →
   открывается ИМЕННО ЧАТ этой сделки (не лента, не список).
3. В чате у boris на ставке видна карточка торга (bargain-card) с суммой и
   кнопками: чипы [−$100][−$200][Своя цена] + [Принять] + [Отклонить].
4. boris жмёт чип-контр (или «Своя цена») → уходит контр $5 200.

### 1B. Грузоотправитель предлагает/контрит → ВОДИТЕЛЬ ОТВЕЧАЕТ (баг владельца!)
Именно тут владелец жаловался: «предложил водителю, а у него НЕТ кнопки
согласиться». Проверить в упор:
5. serik (driver) получает пуш о контр-оффере, тап → открывается чат.
6. В чате у serik на карточке торга ЕСТЬ рабочие кнопки: [Принять контр]
   [Своя цена] [Отклонить] — водитель НЕ в тупике.
7. serik жмёт «Принять контр» → создаётся сделка, в чат падает «🤝 Сделка!
   $5 200», карточка сделки обновляется у ОБОИХ.
8. Проверить обратную ветку: если serik вместо принятия шлёт свою цену (контр
   назад) — boris видит её кнопкой в своём чате и может принять. Торг «пинг-понг».

### 1C. Движение цены и история
9. В карточке торга видно движение «$4 800 → $5 200» (обе стороны видят, как
   сходятся). История цены (proposed→countered→accepted) доступна участникам.
10. API sanity: `npm run qa:bargain` (сквозной тест без UI) — зелёный:
    история корректна, посторонний к истории цены получает 403, телефон
    оферента не утекает.

### 1D. Вход в торг из РАЗНЫХ мест
11. Карточка торга и кнопки работают И при входе в чат из вкладки «Чаты»
    (не только из карточки груза) — недавний фикс резолва cargoId. Проверить оба
    входа.

**Флоу:** `chat_offer_e2e.yaml` (расширить сценарием 1B — ответ водителя на контр),
`bids-visibility.yaml`, `chat_bid_notifications_e2e.yaml`, `deal_bell_price_e2e.yaml`.

## 2. ПУШИ И УВЕДОМЛЕНИЯ (мощно и чётко — требование владельца)
На КАЖДОЕ событие приходит уведомление, и по нему ПОНЯТНО что и куда:
- новая ставка, контр-оффер, принятие, отклонение, новое сообщение, смена
  статуса сделки. Текст = событие + сумма + маршрут.
- Тап по пушу/колокольчику ВСЕГДА открывает нужный чат сделки (deeplink),
  не «в никуда». Бейджи не дублируются (Чаты = сообщения, колокол = события).
- Push на симуляторе/Expo Go ограничен → где недоступно, проверить хотя бы
  in-app уведомление + deeplink; полный push на локскрин — на реальном
  устройстве после сборки.
**Флоу:** `.maestro/12-push-deeplink-bid`, `13-push-badge-sync`,
`unread-badge-flow`, `badge-*`, `chat_bid_notifications_e2e`.

## 3. ГРУЗООТПРАВИТЕЛЬ (boris) — каждая кнопка каждой вкладки
Вход → Грузы (фильтр Откуда→Куда с drill страна→города, чипы, ❤️, Подробнее) →
Машины → Разместить (цена/дата обязательны, USD, публикация→тост→Мои грузы) →
Чаты (торг, звонок WhatsApp/Telegram, вложения открываются на весь экран, голос) →
Профиль (мессенджер+БИН/ИНН, Избранное непустое, язык, версия).

## 4. ВОДИТЕЛЬ (serik) — каждая кнопка каждой вкладки
Верификация 3×2 (удостоверение/паспорт 2 стороны → техпаспорт 2 → права 2, без
селфи, без «Кандас») → Feed → MyWork (ставка: изменить/скидка/чат/отмена; скидка
на принятой заблокирована) → Queue («нет данных» честно) → Chats → Profile
(статус/тир/баллы, язык, версия).
