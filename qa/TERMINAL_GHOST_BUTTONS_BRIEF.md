# ЗАДАЧА для Терминал-Клода: единый ghost-стиль кнопок (обводка) по всему приложению

Решение владельца: убрать «кричащую» сплошную заливку кнопок, сделать **ghost —
прозрачный фон + акцентная обводка (1.5px) + акцентный текст/иконка**. Это чисто
визуальная правка — **обязательно смотри результат на симуляторе/устройстве** на
каждом экране (контраст, читаемость, не сломалась ли вёрстка), не только сборку.

## Уже сделано ассистентом (НЕ переделывать, взять за образец)
- `FeedCard` bottomLeft/bottomRight — ghost (transparent + borderWidth 1.5 +
  borderColor a.main, текст a.main).
- Лента «+ Груз» (`FeedScreen` titleCta) — ghost.
- Карточка сделки: «Чат по заказу», «Подтвердить доставку» в CargoDetail и
  TripDetail — ghost (`dealActionGhost`).

Образец стиля: `{ backgroundColor:'transparent', borderWidth:1.5, borderColor:<accent> }`
+ текст/иконка цветом `<accent>`. Акцент клиента `#FF8400`, водителя `#00E676`
(бери из `v1AccentFor(role)` / v1Colors, не хардкодь роль-цвет наугад).

## Перевести в ghost (остаток)
1. **Публикация:** `CreateCargoScreen` и `CreateTripScreen` — главная кнопка
   «Опубликовать груз/рейс».
2. **Ставка/торг:** `BidModal` submit (`submitBtn`), `BargainCard` primary-chip
   (accept / accept-counter). Danger (reject) — оставить красным.
3. **Мои рейсы (`MyTripsScreen`):** «Начать перевозку», «На границе»,
   «Доставлен», «Подтвердить доставку», accept-counter, «Дать скидку» и пр.
   solid-кнопки → ghost (зелёные driver-CTA — зелёная обводка, не заливка).
4. **Регистрация/верификация:** кнопки «Далее»/CTA на шагах, submit.
5. **DriverDetail:** «Открыть контакт», «Пожаловаться» (уже outline-ish — свести
   к единому ghost).
6. **Прочие solid-CTA**, которые найдёшь по экранам.

## НЕ трогать (осознанно)
- Круглый FAB «+» (Разместить) в таб-баре — фирменный акцент, остаётся заливным.
- Кнопка отправки сообщения (стрелка) в чате — icon-CTA, остаётся акцентной.
- Семантические не-акцентные: отмена/удаление (красный tint), tonal-серые.
- Флаги, тир-точки, чипы-данные.

## Правила
- Единый стиль: одна толщина обводки (1.5px), один радиус, акцент по роли.
- Проверь контраст текста-на-обводке в тёмной И светлой теме.
- i18n не трогаем (тексты те же). app.json version не менять.
- `npm run build:web` зелёный; прогони затронутые Maestro-флоу
  (feed, createcargo, bid-actions, deal-chat) — вёрстка не поехала.
- Коммить в ветку `claude/youthful-cerf-barf3`, в main НЕ лезь (переносит
  ассистент). Скрины «до/после» ключевых экранов в отчёт.
