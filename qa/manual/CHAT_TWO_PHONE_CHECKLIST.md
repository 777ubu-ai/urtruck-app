# Чек-лист чата на ДВУХ телефонах (PASS/FAIL)

Проверка вдвоём, два телефона. По каждому шагу — ставь **PASS/FAIL** и при проблеме
приложи скриншот в `qa/screenshots/chat-matrix/`.

## Актёры
- **Телефон A** — грузовладелец
- **Телефон B** — водитель

## Предусловия
| # | Условие | OK? |
|---|---|---|
| 0.1 | На обоих один и тот же билд UrTruck | ☐ |
| 0.2 | Два РАЗНЫХ аккаунта (A — владелец, B — водитель) | ☐ |
| 0.3 | Уведомления разрешены в Настройках iOS (оба) | ☐ |
| 0.4 | Бейдж иконки разрешён (Настройки → UrTruck → Наклейки/Badges) | ☐ |
| 0.5 | Интернет на обоих | ☐ |
| 0.6 | Есть тестовый груз; B видит его; A — владелец | ☐ |

## Шаги
| # | Действие | Ожидаемый результат | PASS/FAIL | Скрин |
|---|---|---|---|---|
| 1 | B: ставка по грузу | B видит «ставка отправлена» | ☐ | |
| 2 | A: получает уведомление о ставке | колокольчик «Новое предложение $…» + точка | ☐ | |
| 3 | B: «Чат по заказу» → отправить `driver-live-test-001` | сообщение в чате | ☐ | |
| 4 | A (вне чата): сигналы о сообщении | колокольчик + красная точка на «Чаты» (+пуш если свёрнуто) | ☐ | |
| 5 | A: открыть уведомление → видит `driver-live-test-001` | сообщение видно | ☐ | |
| 6 | A: ответить `owner-live-test-001` | сообщение в чате | ☐ | |
| 7 | B (вне чата): сигналы | колокольчик + точка на «Чаты» (+пуш) | ☐ | |
| 8 | B: открыть чат → видит `owner-live-test-001` | ответ виден | ☐ | |
| 9 | Оба: выйти и снова зайти в чат | оба сообщения на месте | ☐ | |
| 10 | Оба: проверить историю | те же 2 сообщения, без дублей, не исчезли | ☐ | |
| 11 | После открытия чата | красная точка на «Чаты» пропала | ☐ | |
| 12 | Тап по пушу/уведомлению | открылся ИМЕННО этот чат | ☐ | |
| 13 | Партнёр | имя/телефон, НЕ «Собеседник», не чат с самим собой | ☐ | |

## Если FAIL
Запиши: номер шага, что произошло, скриншот в `qa/screenshots/chat-matrix/`.

## Про пуш на локскрин 🔔
Пуш на заблокированный экран и бейдж иконки — только на **реальном телефоне с
релизным билдом (TestFlight)**, не в эмуляторе. Если приложение открыто —
колокольчик и красная точка должны работать всегда.
