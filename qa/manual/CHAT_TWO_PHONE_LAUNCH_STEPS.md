# Запуск теста чата на двух телефонах

Есть два пути. **Путь A (Expo Go + локальный backend)** — без новой сборки, проверяет
чат-синхронизацию и in-app бейдж/колокольчик. **Путь B (TestFlight)** — нужен только
для пуша на заблокированный экран (APNS).

---

## Путь A — Expo Go + локальный backend (БЕЗ новой сборки)

Проверяет: ставку, уведомление-колокольчик, чат водитель↔владелец в обе стороны,
красную точку «Чаты». **НЕ** проверяет пуш на локскрин (это только Путь B).

### Условия
- Mac и **оба телефона в одной Wi-Fi** (без «изоляции клиентов» на роутере).
- На обоих телефонах установлен **Expo Go** (из App Store).

### На Mac (обычный терминал)
```
cd ~/Downloads/urtruck-app
git fetch origin
git checkout integration/build-30
git reset --hard origin/integration/build-30
nvm use 20
npm install
```
Узнать локальный IP мака:
```
ipconfig getifaddr en0
```
(пример вывода: `192.168.1.50` — подставь свой ниже)

Запустить **backend с чат-фиксом** (отдельная вкладка терминала):
```
cd ~/Downloads/urtruck-app/backend
python3 -m uvicorn main:app --host 0.0.0.0 --port 8001
```
Запустить **Expo**, указав телефонам адрес локального backend (вкладка 1):
```
cd ~/Downloads/urtruck-app
EXPO_PUBLIC_API_URL=http://192.168.1.50:8001 npx expo start
```
(вместо `192.168.1.50` — твой IP из `ipconfig getifaddr en0`)

### На телефонах
1. Открыть **Expo Go** → **Scan QR Code** → отсканировать QR из терминала Expo.
2. Дождаться загрузки приложения.
3. **Телефон A** — войти под аккаунтом **грузовладельца**.
4. **Телефон B** — войти под аккаунтом **водителя** (другой аккаунт!).
   - Если вход по SMS-коду в MOCK-режиме — код виден в логе backend (вкладка uvicorn).
5. Дальше — по `qa/manual/CHAT_TWO_PHONE_CHECKLIST.md`.

### Важно для Пути A
- Без `EXPO_PUBLIC_API_URL=...` приложение пойдёт в ПРОД (старый backend без фикса) —
  поэтому переменную задать обязательно.
- Пуш на заблокированный экран в Expo Go **не придёт** — это нормально, см. Путь B.
- В Expo Go может мелькать его служебная иконка-загрузчик — это не наше.

## Путь B — TestFlight (нужен ТОЛЬКО для APNS lock-screen)

- **Текущий установленный TestFlight-билд (31) НЕ содержит чат-фикс** — он был собран
  ДО него. Поэтому для проверки пуша на локскрин нужен **новый билд** из
  `integration/build-30`.
- ⚠️ **Сборку не запускаю без твоего разрешения.** Это отдельное решение.
- Что Путь B добавляет сверх Пути A: реальный APNS на заблокированный экран, инкремент
  бейджа на иконке приложения, тап по пушу → открытие нужного чата.

| Красная точка «Чаты» / колокольчик (в приложении) | ✅ | ✅ |
| Пуш на ЗАБЛОКИРОВАННЫЙ экран | ❌ | ✅ |
