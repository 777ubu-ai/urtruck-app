# Чек-лист: проверка чата между водителем и грузовладельцем (2 телефона)

Простая инструкция для ручной проверки. Делается **вдвоём** (например, ты и сотрудник),
на **двух телефонах**. Отмечай галочкой ✅ или ставь ❌, если что-то не так.

---

## Кто есть кто
- **Телефон A** — грузовладелец (отправитель груза).
- **Телефон B** — водитель (перевозчик).

## Перед началом (проверь оба телефона)
- [ ] На обоих телефонах установлен **один и тот же** свежий билд UrTruck (из TestFlight).
- [ ] На телефоне A — вход в аккаунт **грузовладельца**.
- [ ] На телефоне B — вход в аккаунт **водителя** (другой аккаунт!).
- [ ] На обоих разрешены уведомления (Настройки iOS → UrTruck → Уведомления → вкл).
- [ ] У обоих есть интернет.
- [ ] У грузовладельца (A) есть **один активный груз**.
- [ ] Водитель (B) видит этот груз в ленте.

---

## A. Водитель отправляет ставку (Телефон B)
- [ ] 1. Открыть карточку груза.
- [ ] 2. Нажать **«Предложить цену»**.
- [ ] 3. Ввести цену.
- [ ] 4. Отправить ставку.
- [ ] 5. Телефон B показал, что ставка отправлена.
- [ ] 6. На **Телефоне A** появилось:
  - [ ] запись в колокольчике 🔔 «Новое предложение $…»
  - [ ] красная точка/счётчик на колокольчике
  - [ ] (если приложение свёрнуто) пуш на экране телефона *(если не пришёл — см. примечание о пушах внизу)*

## B. Грузовладелец открывает чат (Телефон A)
- [ ] 1. Нажать на уведомление **или** открыть карточку груза.
- [ ] 2. Видно ставку водителя.
- [ ] 3. Нажать **«Чат по заказу»**.
- [ ] 4. Вверху чата — **имя/телефон водителя**, а НЕ слово «Собеседник».
- [ ] 5. Чат привязан к нужному маршруту груза.

## C. Водитель пишет сообщение (Телефон B)
- [ ] 1. Открыть **«Чат по заказу»**.
- [ ] 2. Отправить текст: **`driver-live-test-001`**
- [ ] 3. Выйти из чата и снова зайти — сообщение **осталось** на месте.

## D. Грузовладелец получает сообщение (Телефон A)
- [ ] 1. Если A **не** в чате — пришло:
  - [ ] уведомление/колокольчик
  - [ ] красная точка на вкладке **«Чаты»** внизу
  - [ ] (если свёрнуто) пуш *(см. примечание)*
- [ ] 2. Открыть чат.
- [ ] 3. Грузовладелец видит: **`driver-live-test-001`**

## E. Грузовладелец отвечает (Телефон A)
- [ ] 1. Отправить текст: **`owner-live-reply-001`**
- [ ] 2. Выйти и зайти в чат — сообщение **осталось**.

## F. Водитель получает ответ (Телефон B)
- [ ] 1. Если B **не** в чате — пришло уведомление/точка на «Чаты»/пуш.
- [ ] 2. Открыть чат.
- [ ] 3. Водитель видит: **`owner-live-reply-001`**

## G. Финальная проверка (оба телефона)
- [ ] На обоих телефонах в чате видны **оба** сообщения, в одном порядке.
- [ ] Сообщения **не задвоились**.
- [ ] Сообщения **не исчезли** через пару секунд.
- [ ] Партнёр показан правильно (имя/телефон), **не «Собеседник»**.
- [ ] Красная точка на «Чаты» **пропала** после открытия чата.
- [ ] Тап по уведомлению открыл **именно этот** чат, а не другой.

---

## Если что-то не так — запиши
- Какой шаг (A/B/C/…), что именно произошло, скриншот.
- Особенно важно: «сообщение не пришло второму», «вижу ‘Собеседник’», «чат пустой
  у одной стороны», «задвоилось».

## Примечание про пуш-уведомления 🔔
Пуш на **заблокированный экран** работает только на **реальном телефоне с релизным
билдом** (TestFlight), не в эмуляторе. Если приложение **открыто** — уведомление и
красная точка должны появляться всегда. Если пуш на локскрин не пришёл, но при
открытом приложении всё видно — это нормально для теста, отдельно проверяется на
релизе.
