# ЗАДАЧА для Терминал-Клода: device-баги на реальном iPhone (build 42+)

Эти баги НЕ ловятся симулятором/сайтом — только на реальном устройстве из
TestFlight (build 42, версия 1.0.3). Синхронизируйся, поставь build на iPhone,
воспроизведи по шагам, почини по первопричине, перепрогони. Build не пересобирай
без нужды; если фикс во фронте/бэке — новый build закажет владелец.

## 0. Синхронизация
```
git fetch origin && git checkout claude/youthful-cerf-barf3 && git pull
```
На ветке уже: чистая строка ввода чата + WeChat-панель вложений («+» →
Фото/Камера/Локация/Цена/Фразы), дробный вес, пикер (страны→погранпереходы→
избранное) + «Назад», прокрутка выбора груза. Проверь и это заодно.

## БАГ 1 — Голосовое: своё не проигрывается (P0, «самое важное»)
Симптом: записал 0:27, тап «прослушать» → тишина/«Не удалось воспроизвести».
Уже сделано: `voiceRecorder.play()` сбрасывает audio-режим
(`allowsRecordingIOS:false, playsInSilentModeIOS:true`) + web requestData/blob.
Проверь НА УСТРОЙСТВЕ:
- запись → отправка → воспроизведение у СЕБЯ и у второго телефона;
- формат файла (iOS = m4a/aac), что подписанный URL читается (не 403),
  что `resolveAttachment` даёт абсолютный URL;
- silent-switch (беззвучный режим) — играет ли.
Если не играет — залогируй ошибку expo-av `Sound.createAsync`, покажи причину.

## БАГ 2 — Первое сообщение в чате не грузится (P1)
Симптом: первое сообщение переписки не появляется/«не грузится».
Проверь: `chatAPI.history`/загрузку комнаты при первом открытии (пустой roomId →
резолв по cargo/trip + партнёру), гонку между созданием комнаты и первым
`send`. Воспроизведи: новый чат → первое сообщение → показывается ли сразу и
после реоткрытия.

## БАГ 3 — Вложение файла/документа не прикрепляется (P1)
Симптом: «Документ/файл не грузится». expo-document-picker — НАТИВНЫЙ модуль,
его нет в старых билдах; в build 42 он есть. Проверь на build 42:
- «+» в чате → (панель) и «Прикрепить» в блоке документов сделки →
  открывается системный файловый менеджер, PDF/файл выбирается и грузится
  (`DealAttachments.pickDocument` → `chatAPI.uploadAttachment`);
- получатель открывает вложение.
Если падает — залогируй `DocumentPicker.getDocumentAsync` / upload ответ.

## БАГ 4 — Избранное добавляется по 2/4 (P1)
Симптом: тап ❤️ добавляет сразу несколько; в профиле «Избранное» путается.
Уже сделано: дедуп ленты + гейт favBusy в DriverDetail. Проверь путь ИМЕННО
как владелец: добавляй из карточки водителя (DriverDetail «В избранном») и с
❤️ в ленте; смотри, сколько строк реально создаётся (`GET /favorites`) и
сколько карточек «загорается». Если ❤️ загорается на нескольких карточках —
это один и тот же перевозчик (дедуп это чинил); если в БД реально >1 строки на
один тап — лови двойной вызов favAdd (debounce/guard).

## Отчёт
По каждому багу: воспроизвёлся ли на устройстве, первопричина, что починил
(коммит в ветку), что осталось. Скрины/видео с телефона. Актёры
agent-boris/agent-serik, реальных не трогать.
