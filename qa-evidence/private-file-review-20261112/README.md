## Модель угроз

- Атакующий может узнать/подменить attachment ID или room ID.
- Гость/посторонний пользователь пытается получить чужое вложение.
- Клиент хранит старую подписанную ссылку из legacy ответа API.
- Неожиданный MIME/слишком большой файл/ошибка сети.
