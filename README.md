# 🚛 UrTruck — FTL Market (Китай ↔ СНГ)

Мобильное приложение для грузоперевозок в стиле InDrive.

## ⚡ Быстрый старт

### Шаг 1: Установи на компьютер
1. Node.js — https://nodejs.org (версия LTS)
2. Cursor — https://cursor.com

### Шаг 2: Открой проект
1. Скачай папку urtruck-app
2. Cursor → File → Open Folder → urtruck-app

### Шаг 3: Установи зависимости
```bash
npm install
```

### Шаг 4: Запусти
```bash
npx expo start
```

### Шаг 5: Телефон
1. Установи Expo Go (App Store / Google Play)
2. Отсканируй QR-код

### Шаг 6: База данных
1. supabase.com → создай проект
2. SQL Editor → вставь database/schema.sql → Run
3. Settings → API → скопируй URL и ANON KEY
4. Вставь в src/config/supabase.js
