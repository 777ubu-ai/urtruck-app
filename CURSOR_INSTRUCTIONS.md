# CURSOR INSTRUCTIONS — UrTruck App

## Что это за проект
UrTruck — мобильное приложение для FTL грузоперевозок Китай ↔ СНГ.
Аналог InDrive, но для фур. Две роли: Водитель и Грузовладелец.

## Технологии
- React Native + Expo (SDK 52)
- Supabase (БД + Auth + Realtime)
- React Navigation (Stack + Tabs)
- Expo Image Picker (фото документов)
- Expo Localization (RU/UZ/KZ/CN)

## Архитектура

### Навигация
```
SplashScreen → AuthScreen → RoleScreen → RegScreen → MainTabs
MainTabs: FeedScreen | TrackScreen | WalletScreen | ProfileScreen
Stack: CargoDetail | DriverDetail | ChatScreen
```

### Две роли
- **driver**: видит ленту грузов, может предлагать цену, публикует "Я еду в Китай"
- **client**: видит ленту машин, размещает грузы, покупает контакты водителей

### Монетизация (Beta = всё $0)
- Переменная IS_BETA = true в config/supabase.js
- Когда IS_BETA = true, все платные действия бесплатны
- Визуально показываем зачёркнутую цену: ~~$1~~ $0
- Логируем сколько бы потратил пользователь (таблица transactions)

### База данных (Supabase)
Полная схема в database/schema.sql. Основные таблицы:
- users — все пользователи (phone, role, balance, rating)
- drivers — профиль водителя (truck_type, volume, capacity, plates)
- customers — профиль клиента (company_type, city)
- cargo_posts — грузы (маршрут, цена, статус)
- driver_trips — рейсы водителей ("Я еду в Китай")
- bids — ставки/торг (InDrive стиль)
- chats + chat_messages — переписка с переводом
- reviews — отзывы (двусторонние, 1-5 звёзд + текст)
- transactions — история платежей
- contact_purchases — покупки контактов

### Ключевые фичи для реализации

1. РЕГИСТРАЦИЯ: Телефон → SMS (Supabase Auth) → Выбор роли → Профиль
   - Водитель: фото техпаспорта + селфи + параметры фуры
   - Клиент: имя + тип бизнеса + город
   - Статусы верификации: pending/rejected/verified

2. ЛЕНТА: FlatList с карточками
   - Водитель видит грузы, клиент видит машины
   - Фильтры: тип кузова, маршрут
   - Рейтинг влияет на позицию (ORDER BY rating DESC)

3. ТОРГ (InDrive): Клиент ставит цену, водители предлагают свою
   - Быстрые кнопки: цена клиента, +200, +400
   - Ввод своей суммы
   - Рекомендованная цена = AVG последних 10 сделок на маршруте

4. ЧАТ: После принятия ставки или оплаты контакта
   - Быстрые фразы: "Я на погрузке", "Задерживаюсь", "Выезжаю"
   - Голосовые сообщения (Expo AV)
   - Ручной выбор языка перевода (RU/UZ/KZ/CN)

5. ТРЕКИНГ: 6 статусов
   - Выехал → Погрузка → Очередь на границу → Досмотр → Вышел → Выгрузка
   - При каждом обновлении — точка на карте (координаты)
   - Фото груза обязательно при погрузке

6. КОШЕЛЁК:
   - Beta: показываем ∞, всё бесплатно
   - Будущее: Kaspi, Payme, Click, банковская карта
   - Мультивалютность: USD, CNY, UZS, KZT, RUB

7. ПРОФИЛЬ:
   - Отзывы (текст + звёзды)
   - Тёмная/светлая тема
   - Смена языка (RU/UZ/KZ/CN)
   - Push-фильтр (мои маршруты, от X тонн)
   - Чёрный список
   - Архив сделок
   - Раздел "Обучение" (ссылки YouTube/TikTok)

8. ШЕРИНГ: На каждом грузе/машине кнопка → WhatsApp, Telegram, WeChat
