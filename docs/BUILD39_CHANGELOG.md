# UrTruck — что вошло в build 39 (отчёт по сессии)

Сводка всей работы за сессию (18–19 июля 2026). Всё уже на **вебе (urtruck.kz)**;
нативные пункты оживут после сборки **build 39**. Сгруппировано: общее → водитель →
грузоотправитель → build 39 (нативное) → задачи владельца/сервера.

---

## 🎨 Общее (оба, клиент + водитель)

- **Все иконки приложения → Feather** (46 экранов/компонентов). Единый монохром-стиль
  2026 вместо «сказочных» эмодзи. Флаги стран, цветные тир-точки и глифы типов
  (кузов/груз/цвет) оставлены как данные.
- **Дизайн клиента «Сочный мандарин»** — акцент `#FF8400`, иерархия кнопок, анимации,
  underline-вкладки. Водительский изумруд `#00E676` не тронут.
- **Чат прокачан:** голосовые end-to-end, «печатает…», «в сети», камера/галерея,
  геолокация в чате, фото/голос уходят в правильную комнату сделки, кнопка звонка/маршрут
  подгружаются при входе из «Чаты», выбор **WhatsApp / звонок**, контекстные быстрые фразы.
- **Трекинг «Где машина»:** авто-трансляция позиции водителя (app-wide), живая расшифровка
  (км, скорость, ETA, «на границе»), фоновый GPS (задел под build 39). Фикс: трекинг больше
  не замерзает на статусе «На границе».
- **Накладная CMR** (кнопка «Накладная» в сделке).
- **Статус-таймлайн сделки:** Принят → В пути → На границе → Доставлен.
- **Push/уведомления:** реальная валюта вместо `$`, подсказка «Пока нет предложений» (18ч
  без ставок), события сделки в колокольчик.
- **Контакты:** номер телефона скрыт (тап открывает мессенджер). **«Как это работает»**
  открывается на роли пользователя.
- **Очередь на границе:** убраны демо-данные («15»), честный «нет данных».

## 🚚 Водитель (driver)

- **Новый порядок верификации:** Гражданство → Удостоверение личности (2 стороны) →
  Документы на авто → Параметры фуры. Упрощён до **4 шагов**; селфи и фото фуры убраны,
  чтобы не перегружать.
- **Баг повторной регистрации починен:** при повторном входе данные (ФИО/ИИН/дата/фото)
  подтягиваются, не заставляет проходить заново.
- **Статусы по вехам:** 🟡 Новичок → 🔵 Проверенный → 🟢 Профи (10+ рейсов). «Проверенный»
  даётся сразу после верификации. Шкала доверия 50/80/100.
- **Статус/данные видны в профиле сразу** после верификации (обновление сессии, реальный балл).
- **Бейджи доверия** (надёжный партнёр / опытный перевозчик).
- Backend-фундамент: колонки гражданства и удостоверения (2 стороны), эндпоинты загрузки.
- Документ команде: `DRIVER_DESIGN_SPEC.md` (цвета/кнопки водителя).

## 📦 Грузоотправитель (client)

- **Международный профиль:** блок «Связь» — предпочтительный мессенджер (WeChat / WhatsApp /
  Telegram / Viber) + ID; **БИН/ИНН**; компания. Всё сохраняется на сервере.
- **Валюта по умолчанию — USD** (валюта коридора Китай↔СНГ).
- **Цена всегда обязательна**, дата загрузки обязательна («по договорённости» убрана).
- **Предел скидки** — нельзя ронять цену более чем на 90% (был баг «$5333 → $1»).
- **❤️ Избранное прямо с карточек ленты** (быстро сохранить перевозчика).
- **Перевод городов и типов груза на китайский** (Хоргос → 霍尔果斯, Обувь → 鞋类).
- «Доставлено» и «Архив» разведены (не дублируются).
- Документ команде: `CREATE_CARGO_SPEC.md` (спека экрана «Создание груза»).

4. **OCR удостоверения → ФИО/ИИН** — отдельная бэкенд-работа (автозаполнение техпаспорта и
   прав уже работает).
