📦 КЛИЕНТ — Грузоотправитель (3 вкладки)
1

Мои грузы (MyWork)

MyTripsScreen.js
Шапка
  • BrandBar: стрелка назад | UrTruck | menu → Profile
  • Заголовок: «Мои грузы» + подзаголовок
  • CTA: кнопка [+ Разместить груз], оранжевый фон → CreateCargo
Сегменты (3 вкладки, underline)
  • Ищу машину — мои активные грузы (status=active)
  • Везут — сделки accepted / in_progress / picked_up / at_border
  • Доставлено — сделки completed / delivered
  • Архив (N): toggle-ссылка внизу — отменённые / просроченные
Карточка груза (в «Ищу машину»)
  • Бейдж ГРУЗ (оранжевый) + статус (цвет)
  • Маршрут: Город → Город
  • Описание + мета (кузов, дата)
  • Цена (оранжевый, крупный)
  • Плашка «N предложений» (если bids>0) → Deals (вкладка)
  • Кнопки: Изменить EditCargoModal | Удалить deleteCargo
  • Для истекших: Ещё актуально extendCargo + Изменить дату
Карточка сделки (в «Везут» / «Доставлено»)
  • Бейдж ЗАКАЗ + статус-индикатор
  • Маршрут, груз, тип кузова, цена, дата
  • Подсказка «Следующий шаг»
  • in_progress / at_border: кнопка Подтвердить доставку → delivered
  • accepted: кнопка Отменить сделку cancel
  • Кнопка Чат → Chat (если есть room_id)
  • Кнопка Где машина → TrackTruck
Пустые состояния
  • «Ищу машину»: CTA «Разместить груз» → CreateCargo
  • Остальные: текст без CTA
  • Без токена: «Войдите» → Role

  • Сердечко (избранное) favAdd/favRemove

Сделки (Deals)

ChatsListScreen.js (dealsMode)
Сегмент-переключатель
  • Предложения (N) — входящие ставки водителей (incoming_bids)
  • Чаты — все переписки + бейдж непрочитанных
Раздел «Предложения» (клиент)
  • Аватар + иконка $ + точка «новое»
  • Маршрут + описание груза + сумма (+ встречная если countered)
  • Статус: Новое / Торг / Ожидает
  • Открыть чат → Chat
  • Кнопка X — отклонить ставку rejectBid
Раздел «Чаты»
  • Поиск по имени / компании / маршруту / грузу / госномеру
  • Фильтры: Все | Непрочитанные (N) | Активные | Архив
  • Карточка: аватар, имя+роль, маршрут+груз+вес, статус, сообщение, цена, время, бейдж
  • Сортировка: непрочитанные наверху, далее по last_message_at desc

Деталь груза (CargoDetail)

CargoDetail.js
Содержимое
  • BrandBarWithShare: назад | UrTruck | ShareModal
  • Маршрут (22px) + PhotoGallery + GlassCard «Маршрут» + GlassCard «Цена»
Ставки (клиент = владелец)
  • Каждая: флаг, имя → DriverDetail, рейтинг, сумма, сообщение
  • pending: Отклонить | Встречное BidModal | Чат | Принять acceptBid
  • countered: Отклонить | Чат
Блок сделки
  • DealStatusTimeline: Принят → В пути → На границе → Доставлен
  • Кнопки: Подтвердить доставку | Чат | Отменить
Отзыв (после доставки)
  • 5 звёзд + текст + теги + «Отправить» submitReview

Мои рейсы (MyWork)

MyTripsScreen.js
Шапка
  • BrandBar + «Мои рейсы»
  • [+ Разместить рейс] изумрудный, чёрный текст → CreateTrip
  • Verification Gate: если не approved — модалка (unverified → Citizenship, review → Security)
Сегменты (pill)
  • Мои рейсы (active) | В работе (accepted..at_border) | Завершённые (delivered)

Карточка рейса
  • Бейдж РЕЙС + маршрут + мета + цена
  • Изменить → EditTrip | Для просроченных: Ещё актуально
Карточка заказа (В работе)
  • accepted: Начать перевозку → in_progress
  • in_progress: На границе → at_border + Доставлен → delivered
  • at_border: Доставлен → delivered
  • Отменить cancel + Чат → Chat

Очередь на границе (Queue)

QueueScreen.js
Уровень 1: Хаб
  • Мой номер: ввод госномера + Найти GET /borders/lookup
  • Результат: статус + пункт + время. Слежение (push при смене)
  • Мои номера → TrackedPlates
  • Баннер верификации → Citizenship
  • Самый свободный переход (мини-карточка)
  • Выбор страны: CN / RU / UZ / KG / TM
  • CarGoRuqsat → CargoRuqsatInfo
Уровень 2: Переходы
  • Карточка: название + статус (green/yellow/red) + машин + часов + обновлено
  • Табло (раскрытие) + Забронировать → cgr.qoldau.kz

⚠ КАНОН (нерушимые правила)
  • Вкладок «Чаты» и «Разместить» НЕТ ни у одной роли
  • Переписка живёт внутри «Сделок»; размещение — кнопка внутри MyWork
  • Профиль — НЕ вкладка. Из гамбургера (menu), pushed screen
  • Колокольчик в шапке НЕ возвращать (пушей достаточно)
  • Сделки = ChatsListScreen в dealsMode: сегменты «Предложения | Чаты»
  • Бейдж на Deals = notifUnread + chatUnread
  • Driver акцент: #00E676 (текст на нём: #0C0A09 чёрный, НЕ белый!)
  • Client акцент: #FF8400
  • Фон: #0C0A09 (тёмная тема по умолчанию — ночные рейсы)
  • Все тексты через t(...) — 4 языка (RU/EN/KK/ZH)
