# UrTruck — дизайн-спецификация: ВОДИТЕЛЬ (driver)

Для маркетинга и дизайнеров. Точные значения из кода (`src/theme/designV1.js`),
актуально на 18.07.2026 (войдёт в build 38).

---

## 1. Концепция

Водитель работает **ночью, в дороге, на солнце, в перчатках**. Отсюда три
принципа дизайна:
1. **Тёмная тема — основная** (чистый чёрный фон, минимум свечения экрана
   в ночном рейсе). Светлая — опция.
2. **Изумрудный неон #00E676** — фирменный акцент водителя. На чёрном фоне
   «сияет», как приборная панель.텍ст на неоновых кнопках — **тёмный**
   (#0C0A09): контраст 11.4:1 (WCAG AAA), читается под прямым солнцем.
   (Белый на неоне — 2.07:1, нечитаем — поэтому никогда не используем.)
3. **Крупные тап-цели ≥44pt** — «для перчаток», эмодзи-иконки вместо мелких SVG.

Две роли — два мира: водитель = изумруд, грузоотправитель = мандарин #FF8400.
Пользователь всегда понимает, «в чьём» интерфейсе находится.

## 3. Кнопки водителя (иерархия)

| Уровень | Стиль | Пример |
|---|---|---|
| **Главная CTA** | Плотная заливка `#00E676`, текст `#0C0A09`, скругление 14–16, при нажатии пружина 0.97 | «Разместить рейс», «Предложить цену», «Ещё актуально» |
| **Вторичная** | БЕЗ рамок: мягкая подложка `rgba(148,163,184,0.14)` (серая) или `driverSoft` (зелёная), цвет несёт текст | «Открыть чат», «Изменить», «Где машина» |
| **Опасная** | Красный текст `#EF4444`; фон — бледно-красный `rgba(239,68,68,0.10)` или прозрачный (отмена сделки) | «Отклонить», «Отменить сделку» |
| Статусные шаги | Заливка акцентом по шагу | «🚛 Выехал» → «🛂 На границе» → «✅ Доставлено» |

Цветные рамки вокруг кнопок и карточек — **убраны** (редизайн 18.07).
Карточки: скругление 18–20, hairline-обводка, мягкая тень, статус — цветным
текстом, не ободком.

### Таб-бар водителя (канон, 5 вкладок)
`Грузы · Рейсы · Очередь · Чаты · Профиль` — активная вкладка неон `#00E676`
(pill-стиль), бейдж непрочитанных на «Чаты». Не менять без согласования.

## 4. Статусные цвета (сделка и очередь)

**Таймлайн сделки:** 🤝 Принят `#22C55E` → 🚛 В пути `#FF8400` →
🛂 На границе `#2563EB` → ✅ Доставлен `#22C55E` · ❌ Отменён `#EF4444`.
Пройденные шаги — зелёные с галочкой, текущий — подсвечен акцентом роли.

**Очередь на границе (CGR):** 🔵 в очереди `#2563EB` · 🟠 вызван `#FF8400` ·
🟢 пересёк `#22C55E` · 🔴 отозван `#EF4444`.

## 5. Типографика

Системный шрифт (SF Pro / Roboto). Шкала:
hero 32/900 · h1 26/900 · h2 20/800 · заголовок карточки 16–17/800 ·
body 14/500 · caption 12/500 · подписи 11/600.
**Цены** — крупно (21–28/900) + моноширинные цифры (tabular-nums), цветом
акцента роли. Скругления: поля 14 · карточки 18–20 · пилюли 999.

## 6. Что нового в build 38 (для маркетинга)

**Чат стал полноценным мессенджером:**
- 🎤 Голосовые сообщения (записал — отправил — собеседник слушает)
- 📷 Фото с камеры или из галереи
- ✓✓ «Прочитано», ✍️ «печатает…», 🟢 «в сети»
- ⚡ Умные быстрые фразы — меняются по этапу рейса (погрузка/в пути/граница)
- 🌐 Автоперевод всей переписки (RU/KK/中文/EN)
- 📞 Кнопка звонка партнёру прямо из чата

**Контроль рейса как в такси:**
- Живой трекинг «Где машина» 24/7 — теперь работает и при свёрнутом
  приложении (фоновый GPS); клиент видит км до места, скорость, время прибытия
- Статус-таймлайн рейса: Принят → В пути → На границе → Доставлен
- 📄 Накладная (CMR) одной кнопкой — печатный документ из данных сделки

**Очередь на границе (уникально для Китай↔КЗ):**
- Живое табло погранпереходов, проверка своего номера, пуш «🚛 Ваша
  очередь подошла»

**Удобнее публиковать:**
- Выбор города одним тапом (поиск, недавние, избранное, погранпереходы)
- Публикация живёт 3 дня + продление одним тапом «Ещё актуально»

**Дизайн:**
- Грузоотправитель — новый фирменный «Сочный мандарин» #FF8400, чистые
  карточки без рамок, живые анимации (пружинные кнопки, каскад карточек)
- Водитель — фирменный изумрудный неон, тёмная тема для ночных рейсов
- 🏅 Бейджи доверия у водителей: «Надёжный партнёр», «Опытный перевозчик»
