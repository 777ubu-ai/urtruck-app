# 🚛 Экран «Создание груза» — полная спецификация (UrTruck, 2026)

Готово к передаче разработчикам/дизайнерам или загрузке в Claude Code.
Документ описывает экран **«Создание груза»** целиком: структуру, поведение
каждого элемента, интерактив, визуал и «фишки» — в привязке к **реальной**
архитектуре UrTruck (а не абстрактному приложению).

## 0. Контекст проекта (обязательно к прочтению)

- **Стек:** React Native + Expo SDK 52 (JS), деплой в web/PWA (urtruck.kz) и в
  нативные iOS/Android. Никаких web-only API (`window`/`document`).
- **Экран:** `src/screens/CreateCargoScreen.js` (роль **client / грузоотправитель**).
  Симметричный экран водителя — `CreateTripScreen.js` (правки дублировать зеркально).
- **Тема:** тёмная по умолчанию (ночные рейсы), поддержка светлой. Токены —
  `src/theme/designV1.js` (`useV1Colors()`), не хардкодить цвета.
- **Локализация:** 4 языка RU / KK / ZH / EN, все тексты строго через `t(...)`
  (`src/utils/i18n.js`, ключи симметричны по всем языкам — иначе падает `qa:i18n`).
- **Города:** локализуются на язык интерфейса через `localizePlace()` (`src/utils/places.js`).
- **Типы груза:** справочник + перевод — `src/utils/cargoTypes.js` +
  `localizeCargoName()` (`places.js`).

## 1. Каноны UrTruck (нельзя нарушать)

1. **Цена всегда обязательна.** «По договорённости» удалена намеренно — не
   возвращать. Валидация: сумма > 0.
2. **Дата загрузки обязательна.**
3. **Валюта по умолчанию — USD** (валюта коридора Китай↔СНГ). Умная подстановка
   по стране — опционально (RU → RUB), Китай остаётся USD.
4. **Модель А (срок жизни):** публикация живёт 3 дня (дата + 2), потом уходит из
   ленты; напоминания владельцу +1/+2/+3; продление одним тапом «Ещё актуально».
5. **Никаких seed/demo-данных** в проде.
6. Экран оборачивается в `SafeAreaView`, стили — через `StyleSheet.create()`.

## 3. Структура экрана (сверху вниз)

### Хедер
- Слева: «← Назад».
- Центр: «Создание груза» (`t('create_cargo_title')`).
- Справа: **прогресс-бар заполненности** с %, цвет — акцент клиента `#FF8400`,
  зелёный при 100%. Считать по обязательным полям (маршрут, описание, тип,
  дата, вес/объём, цена).

### Блок 1. Маршрут «Откуда → Куда»
- Два поля, открывают `LocationPickerModal` (Bottom Sheet):
  - поиск по городу/стране; вкладки **Популярные / Страны / Недавние**;
    двухуровневый выбор страна→город; «📍 Определить город» (геолокация — уже есть `useGeo`).
- **Кнопка «🔄 Поменять местами»** между полями — свап значений + обновление
  подсказок (валюта/курс).
- Умная подстановка: Китай → первыми Гуанчжоу/Иу/Урумчи/Алашанькоу/Сиань;
  КЗ → Алматы/Астана/Шымкент; РФ → Москва/СПб/Новосибирск.

### Блок 2. Описание груза
- Однострочное поле, placeholder `t('cargo_desc_ph')` («Электроника, текстиль…»),
  лимит 100 символов. Автодополнение из `searchCargoTypes()`.

### Блок 3. Параметры
- **Строка 1:** Тип кузова (Bottom Sheet) · Дата загрузки (календарь):
  пресеты «Завтра / +3 дня / След. неделя», режим одна дата ↔ диапазон,
  прошлые даты серые, формат по локали (КЗ `ДД.ММ.ГГГГ`, Китай `ГГГГ-ММ-ДД`).
- **Строка 2:** Вес (т) · Объём (м³). Пресеты веса кнопками. Мягкая валидация:
  вес/объём несоответствие → предупреждение, не блок.

### Блок 4. Оплата
- Сумма (разделители пробелами) + валюта справа (Bottom Sheet: 🇰🇿 KZT / 🇨🇳 CNY /
  🇺🇸 **USD (по умолчанию)** / 🇪🇺 EUR / 🇷🇺 RUB, поиск).
- **Способ оплаты:** Безнал / Нал / Любая (по умолчанию «Любая») — 🆕 новый столбец.
- ⚠️ «Договорная» НЕ добавлять (канон §1).

### Блок 5. Фото груза (необязательно)
- «+ Добавить фото» → камера/галерея, до 5 миниатюр с удалением. Подсказка снизу.

### Блок 6. Подсказка доверия
- «Проверенные профили получают больше откликов…» + ссылка на профиль.

### Блок 7. CTA «Опубликовать груз»
- Широкая кнопка, акцент `#FF8400`, скругление. Валидация обязательных полей
  (маршрут, описание, тип, дата, вес/объём, **цена>0**) → незаполненные красным →
  публикация + тост.
