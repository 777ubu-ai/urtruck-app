## 11. ErrorBoundary — не показывает stack trace в production?

❌ **ЧАСТИЧНО.** `ErrorBoundary.js:46`:
```js
<Text style={s.detail}>
  {this.state.error?.message || 'Unknown error'}
</Text>
```
- **Stack trace** не показывается — ✅
- **error.message** показывается — это может содержать технические детали (например, `"Cannot read property 'x' of undefined"`)
- Stack всё равно **отправляется на сервер** (`stack: error?.stack?.slice(0, 2000)`) — это ок для логирования

**Вердикт:** Stack trace скрыт, но `error.message` может быть техническим. Лучше заменить на generic текст.
