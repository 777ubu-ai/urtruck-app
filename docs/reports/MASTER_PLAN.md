# UrTruck — Мастер-план реализации

Дата: 16.07.2026. Основа: 8 глубоких аудитов кода (чат, воронка маркетплейса,
доверие/деньги/трекинг, вход+регистрация водителя, путь грузоотправителя,
рабочий день водителя, периферийные экраны, дизайн-система).
Порядок этапов = порядок работы. Внутри этапа — по приоритету.

Правило работы: перед каждым этапом, который трогает навигацию / FeedScreen /
MyTripsScreen / i18n / backend registration / chat — перечень файлов и рисков,
подтверждение владельца, затем код (см. CLAUDE.md, Graphify-gated).

## Порядок и логика

0 → 1 — убираем риски и неправду (нельзя расти на лжи и с реджект-риском).
2 → 3 — конверсия: сначала клиент (грузы = топливо маркетплейса), потом водитель.
4 — удержание: возвращаем людей в апп.
5-6 — параллельно: читаемость на солнце + вынос мусора.
7 — полировка регистрации.
8 — большие ставки по отдельному решению.

Деплой: web — по мере готовности этапов (CI на main), iOS — копим в build 36+.
