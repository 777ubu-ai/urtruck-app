## Воспроизведение до исправления

- `CargoTypeInput` синхронизирует состояние поля через `localizeCargoName(value, lang)`.
- `localizeCargoName` обрезает исходное значение через `.trim()`. Наблюдаемый результат: `"Оборудование в деревянных ящиках "` превращается в `"Оборудование в деревянных ящиках"`. Для поля ручного города прежний просмотр указывал прямое сохранение значения; отдельную проверку ввода города ещё предстоит выполнить, причину потери пробела там не устанавливал.
- Отправка формы отдельно уже очищает описание через `.trim()`; вводимую строку это не оправдывает, так как обрезка должна происходить только при отправке.
