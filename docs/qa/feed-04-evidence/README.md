# FEED-04 evidence

Папка предназначена для доказательств финального QA2-кандидата.

Пока здесь нет скриншотов и записей экрана: кандидат не установлен на QA2,
клиентская сборка не создана, а физические сценарии не запускались. Не
подменять эти проверки скриншотами старой версии. После установки сохранить
обезличенные доказательства с моделью устройства, ОС, версией приложения,
build и source SHA; реальные контакты и тексты объявлений не публиковать.
