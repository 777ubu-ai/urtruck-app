## Изменения кандидата

- Карточка показывает «Показать» / «Свернуть», прямой WhatsApp с подтверждённым международным номером и черновиком UrTruck; отправка не производится автоматически. Копирование телефона остаётся отдельно. Telegram-контакт и исходный пост имеют отдельные действия. Share-copy копирует обе ссылки магазинов.
- Действия карточки локализованы отдельным словарём для RU/KK/EN/ZH/TR/UZ/KY/TG/BE.
- Для источников старейший непроверенный хвост теперь идёт в порядке, соответствующем индексу публикации; до изменения запрос использовал временную сортировку большого 10-дневного набора на каждом тике.
- Ошибка повтора журналируется только классом исключения, без текста ошибки и данных объявления.
- Повторная отправка записей после 10-дневного срока отключена. Outbox-записи сохраняются, не очищаются и отдельно считаются как `pending_expired`.
- Контроль очередей теперь различает ожидание backoff, готовую очередь, рост outbox, очередь входных сообщений до разбора и недоставленные истёкшие записи.
- Добавлен read-only `ops/telegram-feed/source_flow_report.py`; отчёт не печатает объявления, телефоны или payload.
