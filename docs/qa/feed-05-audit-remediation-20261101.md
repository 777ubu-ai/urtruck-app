## Дополнительная защита и deploy

- Import endpoint ограничен **12 000 000 байт до JSON/Pydantic**, как по Content-Length, так и по фактически полученным chunks. Обычная проверка importer key сохранена. Это защита размера запроса, не заявление о полном предотвращении DoS.
- Установщик создаёт родительский `backups` при первой установке; обнаруженный отказ без него исправлен.
- Повторная установка сначала останавливает только QA2 health, чтобы timer не прочитал частично заменённый файл.
- При rollback восстанавливаются прежний код, unit-файлы и состояние старого timer; впервые установленный health-модуль и новые units убираются. **Базы не восстанавливаются поверх новых данных.**
- Additive-изменение схемы ограничено тремя столбцами отдельной adapter DB. Старый код может игнорировать эти столбцы. Основная бизнес-БД не мигрируется.
