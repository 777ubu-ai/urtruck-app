## Изменение

Для route-split блоков одного опубликованного поста без локального телефона допускается контакт, если в полном тексте найден ровно один уникальный номер и этот же номер явно присутствует на последней непустой строке. Контакты не переносятся между постами и не берутся из конца более раннего блока. Новая parser revision заставляет существующий published-only мост повторно обработать актуальные подтверждённые публикации; повторная доставка сохраняет идемпотентность по source identity/segment.
