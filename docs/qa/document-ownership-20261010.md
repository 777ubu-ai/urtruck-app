## Причина и исправление
Текст/фото уже получали серверный mine. Документы сравнивали uploader_id с локальным session.user.id, который может отличаться от канонического ID бэкенда после входа. GET attachments теперь возвращает mine отдельно для каждого авторизованного участника. Клиент принимает серверный boolean; для старого API остаётся сравнение непустых ID.
