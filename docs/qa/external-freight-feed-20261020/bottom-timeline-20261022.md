## Изменение
Обычный хронологический список инвертирован средствами FlatList: API сохраняет newest-first и cursor; визуально новые карточки внизу, история сверху. onEndReached теперь относится к верхнему краю истории. Явная сортировка по цене сохраняет прежний порядок.

При фоновом обновлении у нижнего края переход к offset 0. При чтении истории сохраняется видимая карточка и появляется «Новые объявления · N». Повторы не увеличивают счётчик; снятые записи исключаются. Раскрытие описания отключает следование до прокрутки/кнопки. Новые строки локализованы RU/KK/ZH/EN в существующем словаре.
