## Подтверждённые причины и минимальные изменения

1. Классификатор пропускал «Есть машина», кириллическое «ЮК КЕРАК», запрос загрузки. Вопросы/призывы грузоотправителя «Есть свободная машина?», «Ищем свободные машины», «У кого есть машины — звоните» не означают предложение свободной машины. Добавлены смысловые контексты и проверки границ слов, чтобы «шесть машин» не совпадало с «есть машина».
2. Parser не разбирал компактный `Хоргос-Алматы`, явно заданные узбекские исходные/конечные пункты, единственное местоположение `Uluĝchatdan`, отмеченное направление после отдельной строки местоположения. Допускаются только проверенные написания; неизвестные места/конфликтующие маршруты остаются review. Сохраняется исходное написание, страна из флага не выводится.
3. Явно написанные местные девятизначные контакты пропадали. Parser сохраняет их буквально при телефонной маркировке/отдельной строке без добавления кода страны; номера соседних сегментов не наследуются. Цена/валюта не выдумываются. Количество машин извлекается только из явной формулировки.
4. Сборщик принимал записи возрастом до 120h, но начинал чтение только с 24h. Добавлен отдельный durable `app_history` той же существующей Telegram-сессии: максимум 200 сообщений на источник, два источника за scan; приоритет свежего пути сохранён. Cursor движется после durable capture. Завершённый обход перепроверяется раз в 6h для пропущенных правок. Очередь публикаций и её cursors не изменяются историческим обходом.
5. Новая версия parser инициирует ограниченную повторную обработку через существующий мост; причина mixed/unrecognized review различается в журнале. Автоматического массового одобрения нет.

- Исходный код: 15 новых сценариев воспроизводили FAIL, 8 PASS.
