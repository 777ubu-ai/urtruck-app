# PR634: защита даты ставки при публикации на 30 дней

## PRE-FLIGHT

- Base: PR634 `acbb6363c56793f4be80113bc415a99fb24e4850`; локальная рабочая ветка `fix/review-bid-date-guard-20261028`.
- Known-good: PR634 CI40656648657 — PASS; PR633 задаёт публичный срок 30 дней. Физический PASS нового патча отсутствует.
- Разрешение: владелец 28.10.2026 разрешил узкий фикс создания/принятия ставок, сохранив 30 дней и существующее снятие объявлений.
- Scope: `backend/api/marketplace.py`, новые handler-регрессии, hash этого файла в существующей защите baseline и этот журнал. TTL, БД, frontend, роли, FSM, push, GPS и production не изменяются.
- Связи: Graphify AST-only — 15313 узлов / 31487 связей; обычное принятие и принятие встречной цены используют `_finalize_accept_inline`. Создание ставки имеет отдельную проверку. Существующий `parse_market_date` сохраняет одинаковое толкование ISO и DD.MM.YYYY.
- Checks: воспроизведение до патча, запрет вчерашних дат независимо от периодической очистки, разрешение сегодня/завтра, оба типа объявлений, обычное/встречное принятие, сохранность статусов при отказе и существующие тесты TTL/гонок.
- Rollback: revert одного коммита; миграций и изменения данных нет. Перед QA2 deploy — обычный точный SHA/CI gate; перед production необходима приёмка.

## Результат

- До патча реальные `create_bid` обработчики для ISO и DD.MM.YYYY создали ставку на вчерашнюю дату: 2 регрессии FAIL (не был возвращён 409).
- После патча: 60 проверок PASS (`test_bid_route_date_guard.py`, `test_bid_expiry.py`, `test_p0_deal_bid_race.py`), Python 3.12, зависимости из `requirements-test.txt`.
- В этих проверках дата прошла → HTTP409 без новой сделки; дата сегодня/завтра → сделка создаётся, cargo становится taken, trip booked. Отказ не меняет публикацию и не сокращает её 30-дневный срок. Legacy пустые/нераспознанные даты сохраняют прежнее поведение.
- Hash baseline обновлён только для разрешённого marketplace.py; остальные защищённые области сохраняют прежние хеши.
- Проверка конкретных production/QA2 записей, мобильных устройств, backup реальной БД и магазинный rollout этим патчем не выполнялись. Не переносить локальный PASS на устройства или production.
