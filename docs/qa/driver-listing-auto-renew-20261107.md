# Автоматическое продление собственного рейса

Основание: прямое требование владельца 07.11.2026 — водитель не обновляет своё
объявление вручную, оно продлевается на месяц. В существующей политике месяц
означает 30 суток UTC. База патча — PR #681, `0400a24d66e3ba6fd844d8241ee37ce8e0a5226c`.

## Итоговая политика

| Данные | Срок и действие |
|---|---|
| Собственный груз | 30 суток от `published_at`, затем `expired`; ручная перепубликация |
| Собственный активный рейс/предложение машины | Автопродление циклами по 30 суток, без нового ID и без действий водителя |
| Внешние Telegram грузы и машины | 30 суток от исходного `source_published_at` по PR #681, без продления при импорте |
| Каталог перевозчиков | Отдельное хранилище, TTL объявлений к нему не применяется |

`get_conn()` уже вызывает housekeeping: за один UPDATE переносится `published_at`
активного рейса на начало текущего 30-дневного цикла. Пропущенные циклы сворачиваются;
повторный вызов не меняет запись. `created_at`, дата выезда, ID и владелец сохраняются.
Периодические задачи используют тот же DAL; API не требует открывать приложение.
Проверки API и UI поддерживают активный рейс также до очередного housekeeping,
включая границу срока и устаревший клиентский кэш.

Архивные, снятые, отменённые и занятые рейсы не восстанавливаются. Активная сделка
защищает публикацию от housekeeping. Ставки сохраняют отдельный срок 48 часов,
историю, проверки ролей и атомарное принятие. Lifecycle не предлагает вручную
продлевать автоматически продлеваемый рейс; уже поставленное напоминание о старом
сроке блокируется delivery policy. `no_bids` сохраняет один event ID на объявление.

## Проверка и продвижение

Новые behavioral regression: точная UTC-граница/микросекунда до неё, +05:00,
пропущенные циклы, сохранность идентичности, повторный запуск, архив, активная
сделка, отдельный TTL ставки, public API, создание/принятие предложения и lifecycle.
Прежние cargo/FSM/security regression сохраняются с адресным изменением ожиданий
для активного рейса. Graphify AST-only: 14039 nodes / 32621 edges; SQL parser
недоступен, схемы и SQL прочитаны напрямую; Gradle не относится к патчу.

Миграций схемы и массового восстановления нет. Сначала независимый review и CI
PR #681, затем review связанного патча и штатное QA2-продвижение с backup/restore
и health. Production и stores этим документом не разрешены.

Откат: revert патча и штатный code-only deploy предыдущего SHA. БД и историю не
перезаписывать. Уже продлённый `published_at` остаётся действующим ещё до 30 суток;
старый код снова начнёт истекать по окончании этого срока. Старые APK без нового
helper получают обновлённую дату после server housekeeping/refresh; офлайн-кэш
старого APK на границе требует отдельной физической проверки.
