## Реализация
- Выбор роли: водитель первым, грузоотправитель вторым; до выбора кнопка недоступна.
- Обе формы: подтверждённая почта, имя, телефон с выбором телефонного кода страны. Нет ИИН/ИНН/БИН, даты рождения, компании, адреса, обязательной машины.
- Общий светлый фон, зелёная основная кнопка, переключатель существующих языков. Переключатель получает forceLight только внутри регистрации, другие экраны сохраняют прежнюю тему.
- Номер хранится полностью, с кодом страны. Проверены KZ/CN/UZ, вставка полного номера, недопустимая длина и Unicode-цифры.
- Успех показывается после сохранения профиля (и complete-basic у водителя); через 1,5 секунды проверяется актуальность аккаунта, назначается роль и открывается существующий Main.
- Сохранены блокировка повторных запросов и проверки текущего bearer. Ошибки API сохраняют введённые поля; ошибка локального завершения показывает повторный вход. Смена аккаунта во время ожидания не меняет роль новой сессии.
- PATCH содержит только name, phone, role. Дополнительные ранее сохранённые сведения не очищаются.

Небольшое отличие от цветов макета для читаемости: вторичный текст #606F83 вместо #657489 (4,63:1 на #F7F3EC); текст ошибок #CB3636 (4,61:1), иконки/границы ошибок остаются #B85454. Белый текст на #168759: 4,52:1.
