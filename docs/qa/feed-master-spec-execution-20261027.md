## Первый патч: контакты и фильтры

- API добавляет `source_contacts`: распознанные номера полного поста, не назначенные текущему блоку. Локальные контакты не заменяются. Работает на существующих строках без сброса дат/сроков/закладок и без миграции схемы.
- Нормализация копии текста распознаёт невидимые разделители, цифры-клавиши, арабские цифры и подпись «Номер». Исходник остаётся неизменным; цена/вес/дата/ID/номер заказа исключаются адресными тестами.
- Цена сохраняет записи без цены после записей с ценой; keyset-курсор проходит обе части без повторов. Смешанные валюты по-прежнему объясняются с возвратом к дате, без ложного сравнения разных валют.
- Панель фильтров больше не перекрывает верхние кнопки. Пустое поле допускает выход, есть крестик/затемнение/ручка/Back, клавиатура закрывается явно. Сброс текущего условия сохраняет соседние; общий сброс обозначен отдельно.
- Счётчик нового клиента считает объявления, а не контакты справочника. Старый параметр API `include_carriers` сохранён для совместимости; справочник остаётся отдельным типом карточки с предупреждением о неизвестной доступности.
- Кнопка новых объявлений учитывает поздний перерасчёт высот виртуального списка web. Исправление подтверждено тем же сценарием, на котором воспроизведён сбой.

Проверки: полный изолированный backend — 1725 PASS до последнего расширения телефонных подписей; после него адресный повтор parser/DAL/API/vehicle/owned. Frontend — 1607 PASS, повтор runtime после правки прокрутки PASS. Lint — 591 файл PASS. Web build с явным QA2 target и очисткой старого Metro-кэша PASS. Playwright внешней ленты — 36/36 PASS. В других проверенных исходных текстах есть только маршруты/вес/цена без цифрового контакта: они не считаются доказанно безтелефонными до проверки Telegram entities/медиа.
