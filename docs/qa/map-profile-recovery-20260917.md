## Найденные и исправленные дефекты

1. ORS отклонял длинный маршрут по лимиту 6000 км. Прежний fallback делил запрос в линейной промежуточной точке, оказавшейся вне дорожной сети: HTTP 404/code 2010. Теперь синтетические границы подтверждает HGV snap endpoint; максимум пять кандидатов на границу, радиус 2 км, исходные адреса сохранены. Непривязанные точки и разрыв между геометриями более 5 м приводят к ошибке, а не к выдуманной линии. Максимум 16 участков.
2. Неудачный ORS-запрос на китайском направлении выполнялся дважды за один HTTP-запрос. Повтор одного и того же провайдера исключён; другой провайдер остаётся доступным.
3. Нативная карта после HTTP 502 бесконечно показывала «Строим маршрут». Добавлены ошибка, ручной повтор, отмена при выходе и ограничение ожидания. Повреждённая геометрия отвергается целиком.
4. Back профиля находился внутри ScrollView и исчезал при прокрутке. Шапка закреплена вне списка; область кнопки 44×44.
5. На Android 058 профиль показывал номер iOS `(49)`. Версия берётся из установленного APK/IPA через expo-application, fallback строго по платформе.
