# 🤖 UrTruck — ПЛАН AI-АГЕНТОВ
# Реализация в Фазе 7 (после запуска приложения)
# Все агенты работают на сервере (Supabase Edge Functions)

---

## Агент 1: МОДЕРАТОР
**Задача:** Проверка документов водителей
**Технология:** OCR (Google Vision API / Tesseract)
**Логика:**
- Водитель загружает фото техпаспорта
- Агент распознаёт текст: марка, номер, год выпуска
- Автозаполняет данные в профиле
- Сверяет селфи с фото в документе
- Ставит статус: 🟡 → 🟢 или 🔴
**Сервер:** Supabase Edge Function, триггер на upload в Storage

---

## Агент 2: ПЕРЕВОДЧИК
**Задача:** Перевод сообщений в чате
**Технология:** Google Translate API / DeepL API
**Логика:**
- Водитель отправляет сообщение на русском
- Агент определяет язык получателя
- Переводит и добавляет поле translated_text
- Поддержка: RU ↔ UZ ↔ KZ ↔ CN
**Сервер:** Supabase Edge Function, триггер на INSERT в chat_messages

---

## Агент 3: ЦЕНОВОЙ АНАЛИТИК
**Задача:** Рекомендованная цена на маршруте
**Технология:** SQL + простой алгоритм
**Логика:**
- При создании cargo_post берёт последние 20 сделок на маршруте
- Считает AVG, MIN, MAX цены
- Возвращает диапазон: "$2800–3400"
- Учитывает сезонность и тип кузова
**Сервер:** Supabase Database Function (PostgreSQL)

---

## Агент 4: PUSH-ДИСПЕТЧЕР
**Задача:** Умная рассылка уведомлений
**Технология:** Expo Push Notifications + фильтрация
**Логика:**
- Клиент выкладывает груз (tent, Иу→Алматы, 20т)
- Агент находит водителей: truck_type=tent, маршрут совпадает
- Отправляет push только подходящим (не всем 1000)
- Учитывает настройки push-фильтра водителя
**Сервер:** Supabase Edge Function, триггер на INSERT в cargo_posts

---

## Агент 5: АНТИФРОД
**Задача:** Защита от мошенников и спама
**Технология:** Правила + ML (позже)
**Логика:**
- Фейковые аккаунты: 5+ регистраций с одного IP
- Спам-ставки: 20+ ставок за час
- Кидалы: 3+ отмены подряд без причины
- Автодействие: понижение рейтинга, бан, алерт модератору
**Сервер:** Cron job каждые 30 минут

---

## Агент 6: FAQ-БОТ (ПОДДЕРЖКА)
**Задача:** Ответы на типовые вопросы
**Технология:** Claude API / GPT API
**Логика:**
- "Как пополнить баланс?" → инструкция
- "Где мой груз?" → показать статус трекинга
- "Как отменить заказ?" → кнопка отмены
- Не может решить → переключает на живого оператора
**Сервер:** API endpoint, Claude Sonnet для ответов

---

## Агент 7: КОНТЕНТ-ГЕНЕРАТОР
**Задача:** Создание карточек для соцсетей
**Технология:** Canvas API / Sharp (Node.js)
**Логика:**
- Водитель завершил рейс
- Кнопка "Поделиться" генерирует картинку:
  - Маршрут: Иу → Алматы
  - Цена: $3200
  - Рейтинг: ★4.8
  - Логотип UrTruck
- Водитель выкладывает в TikTok/Instagram
- Бесплатная реклама для UrTruck
**Сервер:** Supabase Edge Function
