# Changelog

Все заметные изменения веб-версии UrTruck (urtruck.kz) фиксируются здесь.
Формат — [Keep a Changelog](https://keepachangelog.com/), версии — [SemVer](https://semver.org/).

Нативные билды (App Store / Google Play) версионируются отдельно в `app.json`
(`version` / `buildNumber` / `versionCode`) и в этот файл не попадают.

## [2.0.9] - 2026-07-30
### Changed
- **Один чат на пару пользователей вместо пары+груз/рейс.** `_deal_key`
  (backend `api/chat.py`) раньше включал `cargo_id`/`trip_id` — тот же
  собеседник, но другой груз/рейс, давал отдельную комнату. В «Сделках»
  → «Чаты» это выглядело как дубли (часть вообще без сообщений). Теперь
  ключ — только отсортированная пара участников; переписка про разные
  грузы/рейсы с одним и тем же человеком идёт в одну комнату.
  Затрагивает только НОВЫЕ комнаты — уже существующие (созданные до
  деплоя) не трогает и не сливает: `_migrate_canonical_rooms` одноразовая
  и не пересчитывает старые `deal_key` задним числом. Ретроактивное
  слияние существующих дублей — отдельная задача (риск для FK в
  deals/notifications), сознательно не в этом релизе.
  Проверено локально: два сообщения о двух разных рейсах одному
  водителю попадают в один `room_id`.

## [2.0.8] - 2026-07-30
### Fixed
- **TripDetail «Написать водителю» открывал чат без адресата.** `driverId`
  (state) заполнялся только внутри `applyDeal()` — то есть только когда
  сделка уже существует. Кнопка же именно для случая "сделки ещё нет",
  так что `driverId` был всегда `null` в момент клика: чат открывался
  без partner id, показывал generic "Пользователь UrTruck" вместо
  реального имени водителя, а при попытке написать backend отвечал 400
  (`room_id или to_user_id обязателен`) — сообщение физически не уходило.
  Теперь используется `trip.driverId`/`trip.driverName` (доступны сразу
  из `normalizeTrip`, без деалов). Проверено локально: имя резолвится
  сразу, сообщение реально доставляется.

## [2.0.7] - 2026-07-30
### Added
- Backend: `POST /admin/cleanup-fake-trips-2026-07-30-batch2` — второй
  разовый admin-эндпоинт. Owner подтвердил, что оставшиеся 3 "именных"
  аккаунта (Cvbbb Zcvvvb/+7747..., Ali Li, Жиенгалиев Миржан) — тоже
  внутренние тестовые/dev-аккаунты, несмотря на пройденную OTP-
  верификацию. Удаляет их оставшиеся 21 рейс той же safe-схемой
  (dry_run по умолчанию, пропуск при ставках/сделках). 4 рейса с
  реальными ставками намеренно не включены — по ним отдельно
  проверяется bidder_id перед удалением.

## [2.0.6] - 2026-07-30
### Added
- Backend: одноразовый admin-эндпоинт `POST /admin/cleanup-fake-trips-2026-07-30`
  (Basic Auth) — удаляет 9 конкретных сид/дубликат-рейсов с прод-фида
  (driver_name=null/мусорное имя, verified=false, маршруты дублируют
  реальные записи). `dry_run=true` по умолчанию — только показывает
  список, `dry_run=false` удаляет. Пропускает записи, если на них есть
  ставки/сделки (та же защита, что у `cleanup-stale-listings`).
  Список id захардкожен вручную по owner-запросу, не общий алгоритм.

## [2.0.5] - 2026-07-29
### Changed
- Экран рейса (клиент смотрит чужой рейс): CTA «Предложить цену» заменён
  на «Написать водителю» — по нажатию сразу открывает чат с водителем,
  без модалки ставки. Владелец сознательно отменил решение Stage 20
  (тогда эту же кнопку убрали из-за пустых пре-бид чатов) — если проблема
  вернётся, торг остаётся доступен внутри комнаты чата (BargainCard).
  `BidModal` на этом экране больше не используется, импорт/state убраны.

## [2.0.4] - 2026-07-29
### Added
- Тип кузова на карточке ленты (например «Тент · 10 т») — раньше в
  компакт-режиме тип кузова пропадал (перекрывался строкой meta).

### Changed
- Цена на карточке чуть увеличена и заметнее (17px → 19px, letter-spacing).

### Fixed
- Убран чёрный focus-outline браузера на активной вкладке нижнего меню
  (web) — `outlineStyle: 'none'` на ячейке таб-бара.

## [2.0.3] - 2026-07-29
### Fixed
- 2.0.2 решил перекрытие только для последней карточки (отступ снизу).
  Реальная причина перекрытия была в другом: floating-кнопка «+ Разместить
  груз» была прозрачной (ghost-стиль, только обводка) — карточки,
  проезжающие под ней при скролле, буквально просвечивали сквозь текст
  кнопки. Кнопка сделана непрозрачной (сплошная заливка accent-цветом,
  тёмный текст поверх — тот же контраст-фикс, что и у driver-кнопок).

## [2.0.2] - 2026-07-29
### Fixed
- Клиентская лента: floating-кнопка «+ Разместить груз» перекрывала цену
  последней карточки при прокрутке списка до конца — добавлен нижний отступ
  списка (`paddingBottom`) под высоту кнопки.

## [2.0.1] - 2026-07-29
### Changed
- Клиентская лента («Машины»): цена на карточке уменьшена (~20%, 21px → 17px).
- Увеличен отступ между карточками ленты (10px → 14px, в компакт-режиме 7px → 10px).
- Кнопка «+ Разместить груз» вынесена из шапки экрана в плавающую (floating)
  кнопку поверх ленты — не отнимает место у заголовка.
- Сердечко «в избранное» на web показывается только при наведении курсора
  (hover); на мобильных (native) — как раньше, всегда видно.
